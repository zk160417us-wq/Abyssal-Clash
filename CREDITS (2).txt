ADDING YOUR OWN MODELS
1. Download a .glb file (Sketchfab "Downloadable", Poly Haven, Kenney, Quaternius...).
2. Put it in this folder (public/models/).
3. Add its file name to a slot in models.json, e.g.  "truck": { "files": ["CesiumMilkTruck.glb", "my_bus.glb"], "length": 6.2 }
   Slots: car, truck, pedestrian (animated people - empty by default), sofa, chair, animal.  "length"/"height" = size in metres.
   If a model faces the wrong way, add  "rotate": 90  (or 180 / -90).
4. Restart the page. Keep models small (under ~50,000 triangles) except the showroom "car".
